Python dependency upgrades, proven

Prove it
before you ship.merge.

UpgradeGuard builds two clean Python environments, one before and one after a single package change, runs your tests in both, and returns Accept, Reject or Insufficient Evidence. Your own setup is never touched.

Start How it works

Two environments. One change.

01

Freeze

Your requirements are read as they are today and rebuilt in a clean environment. Your own setup is never touched.

02

Change one

A second environment is built with one package moved to the version you asked for. Nothing else changes.

03

Test both

Your own tests run in both. Only failures that are new after the change count against the upgrade.

04

Verdict

Accept, Reject or Insufficient Evidence. Every reason points to a file that was saved.
